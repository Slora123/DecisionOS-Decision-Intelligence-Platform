# DecisionOS – Decision Intelligence Platform

DecisionOS is a modern frontend-only Decision Intelligence SaaS platform designed to help individuals and teams organize, visualize, and evaluate complex decisions through an intuitive and interactive workspace. Instead of relying on scattered notes or spreadsheets, users can map decisions on a visual canvas, connect dependencies, assess risks, compare alternatives, and gain actionable insights using realistic mock data.

The platform features a drag-and-drop decision canvas with connected decision cards, interactive dashboards displaying key metrics and trends, AI-inspired recommendation panels, customizable decision templates, and collaboration-focused interfaces for tracking activities and discussions. Rich data visualizations, confidence indicators, risk analysis, and responsive layouts provide a seamless experience across desktop and mobile devices. The application also includes modern productivity features such as global search, a command palette, dark mode, notification center, and smooth animations to deliver a premium SaaS experience.

By transforming complex decision-making into a clear visual workflow, DecisionOS enables users to better understand relationships between choices, identify potential risks, and make informed, confident decisions. The project demonstrates how thoughtful UI/UX design and interactive data visualization can simplify decision intelligence without requiring a backend, making it an engaging, production-ready frontend prototype.

## 🚀 Key Features

- **Infinite Canvas & Decision Cards**: Visual drag-and-drop workspace with connected dependency lines, card customization, and real-time color themes.
- **Canva-Style Floating Toolbars**: Quick tools for node creation, drawing, text, comments, zoom controls, and canvas maps.
- **AI Recommendation Engine**: Actionable insights, confidence scores, and auto-generated decision suggestions.
- **Interactive Dashboards & Analytics**: Track decision health, risk distribution, financial impact, and category breakdowns.
- **Customizable Templates**: Ready-to-use frameworks (Product Launch, Strategic Hiring, Tech Stack Evaluation, etc.).
- **Productivity Suite**: Command palette (`⌘K`), global search, notification center, keyboard shortcuts, and full dark/light theme support.
- **Animated Splash Screen & Hero**: Premium onboarding experience featuring DecisionOS splash intro animation.

## 🛠️ Tech Stack

- **Framework**: React 18 with Vite & TypeScript
- **Styling**: Tailwind CSS, Vanilla CSS, Glassmorphism, Dynamic Gradients
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Charts & Visualizations**: Recharts / SVG Canvas

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Slora123/DecisionOS-Decision-Intelligence-Platform.git
   cd DecisionOS-Decision-Intelligence-Platform
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173`.
